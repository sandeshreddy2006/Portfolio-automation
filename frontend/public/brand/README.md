# Portfolabs logo kit

The mark combines a lowercase-inspired portfolio monogram with the outline of a second page. Use the horizontal logo for navigation, presentations, and other places where the name needs to read at a glance.

| Asset | Use |
| --- | --- |
| `logo.svg` | Primary lockup for paper, white, and other light backgrounds |
| `logo-reverse.svg` | Reverse lockup for dark backgrounds |
| `logo-ink.svg` | Single-color lockup for light backgrounds |
| `logo-paper.svg` | Single-color lockup for dark backgrounds |
| `mark.svg` | Transparent standalone mark for light backgrounds |
| [`app/icon.svg`](../../app/icon.svg) | Square favicon and social avatar |
| [`app/apple-icon.png`](../../app/apple-icon.png) | 180 × 180 iOS home screen icon |

## Palette

| Color | Hex |
| --- | --- |
| Forest ink | `#19211B` |
| Lime | `#DAF977` |
| Paper | `#F7F7EE` |

Keep clear space of at least one quarter of the icon's height on all sides. Use the square icon for spaces under 120 pixels wide. The SVG lettering is drawn as paths, so the files travel without a font dependency.
